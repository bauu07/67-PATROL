MODULO 01 // MARCO TEORICO Y NORMATIVO

EVOLUCION NORMATIVA: ISO 9126 VS. ISO 25000 (SQuaRE)

ISO/IEC 9126 (1991-2001)

LEGADO CLASICO

Establecio el primer modelo formal de calidad del software estructurado en 6 caracteristicas troncales aplicadas tanto a la evaluacion interna como externa del producto.

Caracteristicas: Funcionalidad, Fiabilidad, Usabilidad, Eficiencia, Mantenibilidad, Portabilidad.

ISO/IEC 25000 SQuaRE

ESTANDAR MODULAR

Reemplazo moderno que unifica criterios mediante un sistema de divisiones (2500n a 2504n), integrando explicitamente la Seguridad y la Compatibilidad.

Gestion de Calidad: 2500n
Modelo de Calidad: 2501n
Medicion y Requisitos: 2502n-3n

QA vs. QC vs. Testing

GOBIERNO QA

Delimitacion estricta de dominios para optimizar la gobernanza del ciclo de vida del software (SDLC) y evitar la superposicion de roles operativos.

QA: Proceso preventivo sistemico.
QC: Verificacion de calidad del entregable.
Testing: Ejecucion y deteccion de fallos.
MODULO 02 // INGENIERIA CUANTITATIVA

METRICAS DE CODIGO Y EFICIENCIA DE DEFECTOS (DRE)

Complejidad Ciclomatica V(G)

McCabe (1976)

Mide la complejidad estructural cuantitativa del codigo fuente contando el numero de caminos linealmente independientes a traves del grafo de flujo de control.

V(G) = E - N + 2P
● 1–10: Codigo estructurado, bajo riesgo.
● 11–20: Complejidad moderada, riesgo medio.
● > 50: Codigo altamente inestable y propenso a fallos.

Eficiencia de Deteccion (DRE)

EFICACIA QA

Evalua la capacidad del equipo de desarrollo y QA para capturar errores antes de que el software sea liberado al entorno de produccion.

DRE = B / (B + C) * 100%
Donde B = Errores detectados antes de entrega, C = Errores reportados por produccion.

Objetivo Tecnico Principal
NIVEL 01 Pruebas Unitarias
Funciones, metodos, clases y algoritmos individuales aislados.

NIVEL 02 Pruebas de Integracion

NIVEL 04 Pruebas de Aceptacion (UAT)
Validacion de criterios de negocio funcionales junto al cliente o PO.
Cucumber, SpecFlow, Criterios BDD
Certificar formalmente que el sistema satisface las metas operativas.
